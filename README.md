# Sistema POS para Negocio Local

Punto de venta para negocios pequeños usando laptop + tablet + celular conectados por red local. **Sin nube, sin mensualidades, sin hardware nuevo.**

## La página promocional

Abre **index.html** o visita la demo publicada: https://ariel-rengifo.github.io/sistema-pos/

## Características del prototipo

- Login con 4 roles y permisos (dueño / administrador / cajero / mesero)
- Inventario con código de barras y alertas de stock bajo
- Venta de mostrador con ticket simulado y descuento automático de stock
- Flujo de pedidos: mesero (tablet) -> caja (celular) -> mesa liberada
- Multi-dispositivo real por red local

## Stack

Python + Flask + SQLite + HTML
